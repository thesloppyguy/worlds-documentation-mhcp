## Template Types

### Basic Templates
- **Door Template**: Interactive doors with open/close states
- **Light Switch Template**: Controllable lighting systems
- **Furniture Template**: Base class for furniture items

### Advanced Templates
- **Character Template**: Player and NPC base classes
- **Weapon Template**: Combat system integration
- **Vehicle Template**: Transportation systems

### Specialized Templates
- **UI Template**: User interface components
- **Effect Template**: Visual and audio effects
- **Gameplay Template**: Game mechanics integration

## Performance Guidelines

### Template Limits
- **Active Templates**: Up to 100 per scene
- **Template Instances**: Up to 500 per scene
- **Complex Templates**: Limit to 10-20 per scene

### Optimization Tips
- Use template pooling for frequently spawned objects
- Implement LOD systems for complex templates
- Cull inactive template instances
- Optimize template property updates

## Comparison with Unity Prefabs

| Feature | Horizon Templates | Unity Prefabs |
|---------|------------------|---------------|
| **File System** | Database-driven | File-based |
| **Version Control** | Automatic sync | Manual merge |
| **Collaboration** | Real-time sharing | Branch/merge |
| **Performance** | Optimized for VR | General purpose |
| **Integration** | Native Worlds API | Unity API |
